# MindTrace

MindTrace is a research project studying similarities and differences between human memory and AI memory.

## Current Stage

The project is in the initial research and setup phase.

Do not implement experiments unless the experimental goal is clearly defined first.

## Principles

- Prefer simple, readable research code.
- Do not fabricate experimental results.
- Clearly distinguish hypotheses from measured results.
- Negative results are valid results.
- Make experiments reproducible.
- Use controlled experiments when possible.
- Do not commit external datasets unless redistribution is clearly permitted.

## Workflow

Before implementing a new experiment:

1. Define the research question.
2. Define the hypothesis.
3. Define what will be measured.
4. Identify controls or baselines.
5. Only then implement the experiment.
